# QR Code Generator

A simple and user-friendly **QR Code Generator** that allows users to generate QR codes from text, URLs, or other information using an external API. This project demonstrates how to integrate an API into a web application and dynamically display the generated QR code.

## 🚀 Features

- Generate QR codes from text or URLs.
- Use an external API to generate QR codes.
- Simple and user-friendly interface.
- Generate QR codes quickly and easily.
- Display the generated QR code on the webpage.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Application logic and API integration.
- **QR Code API** – Generate QR codes dynamically.

## ⚙️ How It Works

1. Enter text or a URL in the input field.
2. Click the **Generate QR Code** button.
3. The application sends the required data to the QR Code API.
4. The API generates the QR code.
5. The generated QR code is displayed on the webpage.

## 💻 Getting Started

### Prerequisites

- A web browser.
- A code editor such as Visual Studio Code.
- An internet connection to access the QR Code API.

### Installation

1. Clone this repository:

  
   git clone https://rishabpal21.github.io/QR-Code-/


2. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.

3. Enter your text or URL and generate your QR code.
